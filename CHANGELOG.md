# Changelog

## [0.1.0] - 2026-11-15

### Added

- Translation catalogs for all 24 official EU languages and Ukrainian (25 languages in total).
- 46 validation message keys per language for fields, strings, numbers, dates, emails, URLs, uploads, CSRF and anti-spam checks.
- Standalone integrity tests for consistent keys and placeholders across all locales.
- Installation and contribution instructions for direct use from GitHub without Composer or Packagist.
